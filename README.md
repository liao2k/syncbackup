# 資料夾同步備份

把電腦上指定的資料夾即時同步備份到外接硬碟，在背景低調執行，效能可以調整。

## 安裝與啟動

1. 雙擊 `安裝.command`（第一次執行只需要做一次）
2. 雙擊 `資料夾同步備份.app` 開啟

> 如果 macOS 提示「無法開啟」，請在 app 上按右鍵 → 打開。

## 功能

| 分頁 | 內容 |
|---|---|
| **備份任務** | 新增 / 編輯 / 移除任務、啟用開關、立即同步、預覽變更、開啟來源 / 備份 / 歷史版本 |
| **活動紀錄** | 每個檔案的新增、更新、刪除、錯誤紀錄，可依任務、動作篩選或搜尋檔名 |
| **同步紀錄** | 每次同步的摘要（新增 / 更新 / 刪除數、傳輸量、耗時、結果） |
| **效能設定** | 低調 / 平衡 / 全速 / 自訂；限速、CPU 上限、優先權、自動暫停 |
| **一般設定** | 登入自動啟動、背景執行、隱藏 Dock 圖示、通知 |

### 同步方式
- **鏡像同步**：備份與來源完全一致，來源刪掉的檔案在備份中也會刪除
- **累積備份**：只新增和更新，永遠不刪除備份中的檔案

### 安全保護
- **保留歷史版本**：被覆蓋或刪除的檔案會移到備份位置的 `_備份歷史版本/日期時間/`，保留天數可以設定
- **大量刪除保護**：一次要刪除超過 30% 的備份檔案時先暫停，等你確認後才執行
- **未連接偵測**：外接硬碟沒接上時不會寫入，接回後自動補上這段期間的變更
- 來源資料夾讀取失敗時，不會刪除它在備份中的對應檔案
- 複製時先寫入暫存檔，完成後才替換，中途中斷不會留下損壞的檔案

### 效能控制
| 項目 | 說明 |
|---|---|
| 最大傳輸速度 | 限制每秒寫入外接硬碟的資料量 |
| CPU 使用上限 | 同步執行緒的 CPU 時間比例 |
| 處理優先權 | macOS QoS：「背景」等級會優先使用省電核心，磁碟 I/O 也會讓給其他程式 |
| 每個檔案之間休息 | 降低大量小檔案時的磁碟負擔 |
| 變動後等待 | 把連續的變動合併成一次備份 |
| 定期完整檢查 | 補上即時監控可能遺漏的變動 |
| 自動暫停 | 使用電池時，或系統忙碌時 |

視窗關閉後，程式只會在選單列留一個圖示，介面不再更新，盡量降低資源使用。

## 檔案位置
- 設定與紀錄：`~/Library/Application Support/FolderSyncBackup/`
- 登入自動啟動：`~/Library/LaunchAgents/com.local.foldersyncbackup.plist`

## 注意事項
- 第一次備份「文件」、「桌面」、「下載」時，macOS 會詢問是否允許存取，請按「允許」；如果還是失敗，請到「系統設定 › 隱私權與安全性 › 完整磁碟取用權限」加入 Python
- 捷徑（符號連結）不會被備份
- 外接硬碟如果是 exFAT / FAT 格式，部分特殊字元的檔名可能無法寫入，會顯示在活動紀錄的錯誤中

## 程式結構
```
app.py                     進入點（單一執行個體、選單列）
syncbackup/config.py       設定、效能模式
syncbackup/engine.py       同步引擎（掃描、比對、複製、歷史版本）
syncbackup/service.py      背景服務（即時監控、排程、暫停、硬碟偵測）
syncbackup/throttle.py     限速、CPU 上限、速度量測
syncbackup/history.py      SQLite 活動紀錄
syncbackup/sysutil.py      macOS：QoS、電源、通知、自動啟動、Dock
syncbackup/gui/            介面
```
